## 环境安装：RHEL/CentOS/OpenEuler

```sh
yum install -y make gcc gcc-c++ flex bison ncurses-devel openssl-devel elfutils-libelf-devel bc dwarves
```

## 环境安装：Debian/Ubuntu

```sh
apt-get install -y build-essential flex bison libncurses-dev libssl-dev libelf-dev bc dwarves
```

## 环境安装：clang

```sh
sudo apt install -y clang llvm llvm-dev libelf-dev zlib1g-dev make gcc pkg-config
```

## 环境安装：x86下编译arm64依赖

```sh
sudo apt-get update && sudo apt-get install -y gcc-aarch64-linux-gnu binutils-aarch64-linux-gnu rpm lld bc flex bison libncurses-dev libssl-dev libelf-dev dwarves rsync cpio fakeroot
```
