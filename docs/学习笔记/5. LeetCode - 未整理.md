## 二、排序：`qsort()`

**头文件**

```c
#include <stdlib.h>
```

**函数原型**

```c
void qsort(
    void *base,
    size_t count,
    size_t size,
    int (*compare)(const void *, const void *)
);
```

**参数说明**

| 参数 | 含义 |
| --- | --- |
| `base` | 数组首地址 |
| `count` | 数组元素数量 |
| `size` | 每个元素的字节数 |
| `compare` | 比较函数 |

**比较函数返回值**

| 返回值 | `qsort()` 的理解 |
| ---: | --- |
| `< 0` | 第一个元素应排在第二个元素之前 |
| `0` | 两个元素相等 |
| `> 0` | 第一个元素应排在第二个元素之后 |

### 2.1 `int` 升序排序

```c
int compareIntAsc(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x > y) - (x < y);
}
```

**使用示例**

```c
int nums[] = {5, 2, 8, 1, 3};
int numsSize = sizeof(nums) / sizeof(nums[0]);

qsort(nums, numsSize, sizeof(nums[0]), compareIntAsc);
```

**排序结果**

```text
1 2 3 5 8
```

不要写：

```c
return x >= y;
```

因为 `x >= y` 只能返回 `0` 或 `1`，不能正确表达“小于、等于、大于”三种关系。

也不建议通用地写：

```c
return x - y;
```

因为当数值范围较大时可能发生有符号整数溢出。

### 2.2 `int` 降序排序

```c
int compareIntDesc(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;

    return (x < y) - (x > y);
}
```

### 2.3 `long long` 排序

```c
int compareLongLong(const void *a, const void *b)
{
    long long x = *(const long long *)a;
    long long y = *(const long long *)b;

    return (x > y) - (x < y);
}
```

### 2.4 字符数组排序

```c
int compareChar(const void *a, const void *b)
{
    char x = *(const char *)a;
    char y = *(const char *)b;

    return (x > y) - (x < y);
}
```

**使用示例**

```c
char s[] = "leetcode";

qsort(s, strlen(s), sizeof(s[0]), compareChar);
```

不能把末尾的 `'\0'` 排入数组，所以元素数量使用 `strlen(s)`。

### 2.5 字符串数组排序

```c
int compareString(const void *a, const void *b)
{
    const char *s1 = *(const char * const *)a;
    const char *s2 = *(const char * const *)b;

    return strcmp(s1, s2);
}
```

**使用示例**

```c
char *words[] = {
    "banana",
    "apple",
    "cat"
};

int wordsSize = sizeof(words) / sizeof(words[0]);

qsort(words, wordsSize, sizeof(words[0]), compareString);
```

数组元素本身是 `char *`，而比较函数接收到的是数组元素的地址，因此要按 `char **` 处理。

### 2.6 结构体排序

```c
struct Node {
    int value;
    int index;
};
```

先按 `value` 升序，`value` 相同再按 `index` 升序：

```c
int compareNode(const void *a, const void *b)
{
    const struct Node *node1 = a;
    const struct Node *node2 = b;

    if (node1->value != node2->value) {
        return (node1->value > node2->value)
             - (node1->value < node2->value);
    }

    return (node1->index > node2->index)
         - (node1->index < node2->index);
}
```

### 2.7 LeetCode 二维数组 `int **intervals` 排序

按区间起点升序；起点相同时按终点升序：

```c
int compareInterval(const void *a, const void *b)
{
    int *interval1 = *(int * const *)a;
    int *interval2 = *(int * const *)b;

    if (interval1[0] != interval2[0]) {
        return (interval1[0] > interval2[0])
             - (interval1[0] < interval2[0]);
    }

    return (interval1[1] > interval2[1])
         - (interval1[1] < interval2[1]);
}
```

**使用示例**

```c
qsort(
    intervals,
    intervalsSize,
    sizeof(intervals[0]),
    compareInterval
);
```

## 三、二分查找：`bsearch()`

**头文件**

```c
#include <stdlib.h>
```

使用前，数组必须已经按照相同的比较规则排好序。

```c
int nums[] = {1, 3, 5, 7, 9};
int numsSize = sizeof(nums) / sizeof(nums[0]);
int target = 7;

int *result = bsearch(
    &target,
    nums,
    numsSize,
    sizeof(nums[0]),
    compareIntAsc
);

if (result != NULL) {
    int index = (int)(result - nums);
    printf("下标：%d\n", index);
}
```

`bsearch()` 适合判断某个值是否存在，但不方便处理左边界和右边界。

### 3.1 `lower_bound`：第一个大于等于目标的位置

```c
int lowerBound(int *nums, int numsSize, int target)
{
    int left = 0;
    int right = numsSize;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}
```

返回第一个满足：

```text
nums[index] >= target
```

的位置。

### 3.2 `upper_bound`：第一个严格大于目标的位置

```c
int upperBound(int *nums, int numsSize, int target)
{
    int left = 0;
    int right = numsSize;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] <= target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}
```

## 四、字符串长度与比较

**头文件**

```c
#include <string.h>
```

### 4.1 `strlen()`：字符串长度

```c
char *s = "hello";

size_t length = strlen(s);
```

结果是 `5`，不包括末尾的 `'\0'`。

需要 `int` 时：

```c
int length = (int)strlen(s);
```

`strlen()` 的时间复杂度是 `O(n)`，不要在循环条件中重复调用：

```c
for (int i = 0; i < strlen(s); i++) {
}
```

推荐：

```c
int length = (int)strlen(s);

for (int i = 0; i < length; i++) {
}
```

### 4.2 `strcmp()`：比较完整字符串

```c
int result = strcmp(s1, s2);
```

| 返回值 | 含义 |
| ---: | --- |
| `< 0` | `s1` 字典序小于 `s2` |
| `0` | 内容相同 |
| `> 0` | `s1` 字典序大于 `s2` |

```c
if (strcmp("abc", "abc") == 0) {
    printf("相同\n");
}
```

不能使用：

```c
if (s1 == s2)
```

这比较的是指针地址，不是字符串内容。

### 4.3 `strncmp()`：比较前 `n` 个字符

```c
if (strncmp("abcdef", "abcxyz", 3) == 0) {
    printf("前三个字符相同\n");
}
```

判断前缀：

```c
bool startsWith(const char *s, const char *prefix)
{
    size_t sLength = strlen(s);
    size_t prefixLength = strlen(prefix);

    if (prefixLength > sLength) {
        return false;
    }

    return strncmp(s, prefix, prefixLength) == 0;
}
```

## 五、字符串复制与拼接

### 5.1 `strcpy()`：复制完整字符串

```c
char source[] = "hello";
char destination[20];

strcpy(destination, source);
```

目标空间必须至少是：

```text
strlen(source) + 1
```

动态复制：

```c
char *copyString(const char *s)
{
    size_t length = strlen(s);

    char *copy = malloc((length + 1) * sizeof(*copy));

    if (copy == NULL) {
        return NULL;
    }

    strcpy(copy, s);

    return copy;
}
```

### 5.2 `strncpy()`：最多复制 `n` 个字符

```c
char destination[10];

strncpy(destination, source, sizeof(destination) - 1);
destination[sizeof(destination) - 1] = '\0';
```

`strncpy()` 在源字符串长度大于等于 `n` 时，不保证自动添加 `'\0'`。

### 5.3 `strcat()`：拼接字符串

```c
char result[30] = "hello";

strcat(result, " world");
```

**结果**

```text
hello world
```

目标数组必须有足够空间。

### 5.4 `strncat()`：最多拼接 `n` 个字符

```c
char result[30] = "hello";

strncat(result, " world!!!", 6);
```

**结果**

```text
hello world
```

## 七、字符串分割：`strtok()`

标准 C 没有 Python `split()` 那样直接返回字符串数组的函数，最常用的是 `strtok()`。

**头文件**

```c
#include <string.h>
```

### 7.1 按逗号分割

```c
char text[] = "apple,banana,orange";

char *token = strtok(text, ",");

while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, ",");
}
```

**输出**

```text
apple
banana
orange
```

第一次调用传入字符串：

```c
strtok(text, ",");
```

后续调用传入 `NULL`：

```c
strtok(NULL, ",");
```

### 7.2 多种分隔符

```c
char text[] = "10,20;30 40";

char *token = strtok(text, ",; ");

while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, ",; ");
}
```

第二个参数表示“分隔字符集合”，这里逗号、分号、空格中的任意一个都可以作为分隔符。

### 7.3 分割后转换成整数

```c
char text[] = "10,20,30,40";
int nums[10];
int numsSize = 0;

char *token = strtok(text, ",");

while (token != NULL) {
    nums[numsSize++] = atoi(token);
    token = strtok(NULL, ",");
}
```

### 7.4 `strtok()` 会修改原字符串

`strtok()` 会把分隔符替换为 `'\0'`。

不能直接处理字符串字面量：

```c
char *text = "apple,banana";

strtok(text, ",");  // 不安全
```

应使用可修改数组：

```c
char text[] = "apple,banana";

strtok(text, ",");
```

或者先复制：

```c
char *copy = malloc(strlen(source) + 1);

if (copy == NULL) {
    return;
}

strcpy(copy, source);

char *token = strtok(copy, ",");

/* 使用 token */

free(copy);
```

### 7.5 `strtok()` 会忽略连续分隔符

```c
char text[] = "a,,b,";
```

使用 `strtok()` 得到：

```text
a
b
```

中间和末尾的空字段会被忽略。

### 7.6 自己实现分割，保留空字段

```c
int splitInPlace(
    char *s,
    char delimiter,
    char **parts,
    int maxParts
) {
    if (maxParts <= 0) {
        return 0;
    }

    int count = 0;
    parts[count++] = s;

    for (char *p = s; *p != '\0'; p++) {
        if (*p == delimiter && count < maxParts) {
            *p = '\0';
            parts[count++] = p + 1;
        }
    }

    return count;
}
```

**使用示例**

```c
char text[] = "a,,b,";
char *parts[10];

int count = splitInPlace(text, ',', parts, 10);

for (int i = 0; i < count; i++) {
    printf("[%s]\n", parts[i]);
}
```

**输出**

```text
[a]
[]
[b]
[]
```

### 7.7 不修改原字符串的动态分割函数

```c
char **splitString(
    const char *s,
    char delimiter,
    int *returnSize
) {
    int count = 1;

    for (const char *p = s; *p != '\0'; p++) {
        if (*p == delimiter) {
            count++;
        }
    }

    char **result = malloc(count * sizeof(*result));

    if (result == NULL) {
        *returnSize = 0;
        return NULL;
    }

    int start = 0;
    int index = 0;
    int length = (int)strlen(s);

    for (int i = 0; i <= length; i++) {
        if (s[i] == delimiter || s[i] == '\0') {
            int partLength = i - start;

            result[index] = malloc(
                (partLength + 1) * sizeof(*result[index])
            );

            if (result[index] == NULL) {
                for (int j = 0; j < index; j++) {
                    free(result[j]);
                }

                free(result);
                *returnSize = 0;
                return NULL;
            }

            memcpy(result[index], s + start, partLength);
            result[index][partLength] = '\0';

            index++;
            start = i + 1;
        }
    }

    *returnSize = count;
    return result;
}
```

**释放方式**

```c
for (int i = 0; i < count; i++) {
    free(parts[i]);
}

free(parts);
```

### 7.8 `strtok_r()` 和 `strsep()`

它们不是 ISO C 标准库函数：

- `strtok_r()`：POSIX；
- `strsep()`：BSD/GNU 常见扩展。

LeetCode 环境不一定保证支持。为了可移植性，优先使用 `strtok()` 或自己实现分割。

## 十一、动态内存管理

**头文件**

```c
#include <stdlib.h>
```

### 11.1 `malloc()`

```c
int *nums = malloc(numsSize * sizeof(*nums));

if (nums == NULL) {
    return NULL;
}
```

`malloc()` 申请的内存不会自动初始化。

### 11.2 `calloc()`

```c
int *count = calloc(26, sizeof(*count));
```

底层字节会被清零，常用于：

```c
int *visited = calloc(numsSize, sizeof(*visited));
```

### 11.3 `realloc()`

```c
int newCapacity = capacity * 2;

int *newNums = realloc(
    nums,
    newCapacity * sizeof(*nums)
);

if (newNums == NULL) {
    free(nums);
    return NULL;
}

nums = newNums;
capacity = newCapacity;
```

不要直接写：

```c
nums = realloc(nums, newCapacity * sizeof(*nums));
```

失败时可能丢失原来的指针。

### 11.4 `free()`

```c
free(nums);
nums = NULL;
```

临时内存应在函数内部释放：

```c
int *temporary = malloc(...);

/* 使用 */

free(temporary);
```

返回给 LeetCode 调用者的数组不能在返回前释放：

```c
int *answer = malloc(...);

return answer;
```

## 十二、内存操作

**头文件**

```c
#include <string.h>
```

### 12.1 `memset()`：按字节设置内存

数组清零：

```c
int nums[100];

memset(nums, 0, sizeof(nums));
```

动态数组清零：

```c
memset(nums, 0, numsSize * sizeof(*nums));
```

二维数组清零：

```c
int matrix[10][20];

memset(matrix, 0, sizeof(matrix));
```

不要这样把整数数组设置成 `1`：

```c
memset(nums, 1, sizeof(nums));
```

因为它是把每个字节设置成 `0x01`，不是把每个 `int` 设置成 `1`。

### 12.2 `memcpy()`：复制不重叠内存

```c
int source[] = {1, 2, 3};
int destination[3];

memcpy(destination, source, sizeof(source));
```

动态数组：

```c
int *copy = malloc(numsSize * sizeof(*copy));

if (copy != NULL) {
    memcpy(copy, nums, numsSize * sizeof(*copy));
}
```

### 12.3 `memmove()`：复制可能重叠的内存

删除数组元素：

```c
int nums[] = {10, 20, 30, 40, 50};
int numsSize = 5;
int deleteIndex = 2;

memmove(
    &nums[deleteIndex],
    &nums[deleteIndex + 1],
    (numsSize - deleteIndex - 1) * sizeof(nums[0])
);

numsSize--;
```

### 12.4 `memcmp()`：比较两段内存

```c
int a[] = {1, 2, 3};
int b[] = {1, 2, 3};

if (memcmp(a, b, sizeof(a)) == 0) {
    printf("相同\n");
}
```

### 12.5 `memchr()`：在内存中查找字节

```c
char data[] = {'a', 'b', 'c', 'd'};

char *position = memchr(data, 'c', sizeof(data));

if (position != NULL) {
    int index = (int)(position - data);
}
```

### 14.3 幂函数

```c

```

整数幂更推荐快速幂：

```c
long long fastPower(long long base, int exponent)
{
    long long result = 1;

    while (exponent > 0) {
        if (exponent & 1) {
            result *= base;
        }

        base *= base;
        exponent >>= 1;
    }

    return result;
}
```

## 十八、数组元素数量

真正的数组：




必须另外传递数组长度。

### 19.4 返回二维整数数组

```c
int **buildMatrix(
    int *returnSize,
    int **returnColumnSizes
) {
    int rows = 2;

    int **answer = malloc(rows * sizeof(*answer));
    int *columnSizes = malloc(rows * sizeof(*columnSizes));

    if (answer == NULL || columnSizes == NULL) {
        free(answer);
        free(columnSizes);

        *returnSize = 0;
        *returnColumnSizes = NULL;
        return NULL;
    }

    for (int i = 0; i < rows; i++) {
        columnSizes[i] = 2;

        answer[i] = malloc(
            columnSizes[i] * sizeof(*answer[i])
        );

        if (answer[i] == NULL) {
            for (int j = 0; j < i; j++) {
                free(answer[j]);
            }

            free(answer);
            free(columnSizes);

            *returnSize = 0;
            *returnColumnSizes = NULL;
            return NULL;
        }
    }

    answer[0][0] = 1;
    answer[0][1] = 2;
    answer[1][0] = 3;
    answer[1][1] = 4;

    *returnSize = rows;
    *returnColumnSizes = columnSizes;

    return answer;
}
```

```c
void reverseArray(int *nums, int left, int right)
{
    while (left < right) {

        nums[right] = temporary;

        left++;
        right--;
    }
}
```
